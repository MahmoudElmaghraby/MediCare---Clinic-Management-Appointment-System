# MediCare.Services

Business logic. This project references `MediCare.Data` and is referenced by `MediCare.Web`.

| Folder | What goes here |
| --- | --- |
| `Interfaces/` | Service contracts the web app depends on |
| `Implementations/` | Service classes |
| `Factories/` | Factory classes that build domain objects or services |

Register implementations in `MediCare.Web` with dependency injection when they exist. Nothing is registered yet.
