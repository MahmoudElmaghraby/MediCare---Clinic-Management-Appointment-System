# MediCare docs

Project documents live in this folder. Add a file when the team produces it, and link it from the root `README.md` if newcomers need it.

Suggested contents:

- **Architecture** — N-tier layout, Repository, Unit of Work, Factory, and dependency injection
- **ERD** — entity-relationship diagram for the clinic domain
- **User manual** — how patients, doctors, and admins use the system
- **Setup guide** — local SQL Server, user secrets, and later Azure deployment

Do not commit secrets, real connection strings, or patient data.
